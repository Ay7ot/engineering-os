# Communication format skeletons

Fill these; keep them short and scannable.

## 3P update (Progress, Plans, Problems)

```
Progress
- <what shipped this period, with the outcome>

Plans
- <what is next, with a date>

Problems
- <blocker, the ask, the owner>
```

## Company newsletter

```
<One-paragraph executive summary>

Highlights
- <achievement, with a number where possible>

Upcoming
- <event, date>

Spotlight
- <team or person, what they did>
```

## FAQ answer

```
Q: <the question, in the words the asker used>
A: <direct answer, one or two sentences>

More: <link>
Contact: <who to ask>
```

## Status report

```
Status: <green / amber / red, with one line why>
Metrics: <KPI and value, with the period>
Risks: <risk, impact, mitigation, owner>
Next: <next steps with owners and dates>
```

## Leadership update

```
Context: <why this matters now>
Decision: <what was decided or is proposed>
Ask: <what you need from the reader>
```

## Project update

```
Milestones: <done / in progress / at risk, with dates>
Timeline: <what changed and the new date>
Resources: <what is needed>
Decisions needed: <decision, by when, from whom>
```

## Incident report

```
Summary: <impact in one line>
Timeline: <time, event, in order>
Impact: <who and what was affected, for how long>
Root cause: <the cause, blameless>
Remediation: <what is fixed now>
Follow-ups: <action, owner, date>
```

## Rules

- Lead with the key message.
- State the ask and the owner; an update with no ask is usually a missed one.
- Prefer numbers with units and periods.
- Keep it as short as it can be while still complete.
