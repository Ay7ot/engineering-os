# Marketing idea library

A reference shelf of roughly 139 proven marketing ideas, grouped by category.
Use it to widen the search, then shortlist with the stage, budget and timeline
filters in the main guide. Numbers match the upstream catalogue so a user can
mention an idea by number.

## Common shortlists
- Need leads fast: high-intent search ads, B2B paid social, a free tool as lead generation.
- Building authority: conference speaking, a book, podcasts.
- Low budget: easy keyword ranking, community and comment marketing.
- Product-led growth: viral loops, powered-by marketing, in-app upsells.
- Enterprise: expert networks, conference sponsorship, investor marketing.
