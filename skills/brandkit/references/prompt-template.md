# Prompt template

Fill this structure for every board. Keep the strategy lines that drove the
choices so the image can be regenerated or audited later.

```text
Create a premium brand-kit overview image for "<BRAND NAME>".

Brand strategy:
- category: <category>
- audience: <audience>
- personality: <traits>
- core metaphor: <metaphor>
- logo idea: <how the mark combines symbol, name and category meaning>

Layout:
<3x3 or 2x3 or custom> grid on a dark or light presentation canvas with strong
gutters, clean alignment and refined negative space.

Panels:
- logo cover
- logo concept or construction
- digital application
- tagline or brand essence
- colour system
- typography
- physical application
- image direction
- system detail

Visual mode: <mode>

Palette: <the disciplined palette>

Style: premium, sparse, cinematic, intentional, polished, brand-guidelines deck,
no clutter, no copied real-world logos.

Typography: readable, minimal, high hierarchy, no tiny fake text.

Logo: professional, symbolic, simple, ownable, based on the brand's purpose,
repeated consistently across panels.
```

## Premium detail language
Use a few, never all: small page numbers, tiny footer labels, alignment marks,
construction lines, subtle crosshair grids, thin rules, browser bars, rounded
rectangles, image masks, soft shadows, low-opacity texture, halftone image
treatment, one highlighted word, one accent chip. Premium detail should reward
looking closer.

## Final output standard
The image should read as a premium identity deck, a senior designer's presentation
board, a brand-system case study, a visual launch direction, or a professional logo
concept board: clean, strategic, symbolic, minimal, coherent, art-directed and
implementation-friendly.
