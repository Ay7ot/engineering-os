# Fidelity and tools

## Fidelity tiers

Low fidelity, sketches and paper.
- Time: 30 minutes to 2 hours per flow.
- Detail: boxes, labels and layout, no colour, no type choices.
- Best for: brainstorming, exploring several structures fast.
- Cost: near zero.

Medium fidelity, a design tool.
- Time: 2 to 8 hours per flow.
- Detail: layout, real content, basic click-through interaction.
- Best for: team alignment, structured feedback, reviewing information
  architecture.
- Cost: low, but the file starts to feel precious.

High fidelity, design tool or code.
- Time: 8 hours and up.
- Detail: visual design, interaction states, motion, real assets.
- Best for: developer handoff, user testing, stakeholder sign-off.
- Cost: medium; changes get expensive, so settle structure first.

## Tool selection

Choose by the axis that matters: interactivity, collaboration, or cost.

| Tool | Fidelity | Interactivity | Collaboration | Typical cost |
|---|---|---|---|---|
| Paper and whiteboard | Low | None | In-room | Free |
| Wireframing tool | Low to medium | Clickable links | Shared file | Free to low |
| Design tool | Medium to high | Full click-through | Real time | Free to around 30 per month |
| Code or motion tool | High | Advanced | Repository-bound | Around 12 per month and up |

## Screen skeleton example

A wireframe is a labelled skeleton, not a finished page:

```text
Product page
  Header:     [Logo] [Search] [Cart] [Account]
  Hero:       [Product image] [Price] [Add to cart] [Rating 4.5]
  Details:    Description | Specs | Size guide
  Gallery:    [Main] [Thumb] [Thumb] [Thumb]
  Related:    [Card] [Card] [Card]
  Footer:     Contact | FAQ | Returns | Shipping
```

Reuse this shape for any page: identify the regions, then list the elements and
their state, then mark the primary action.
