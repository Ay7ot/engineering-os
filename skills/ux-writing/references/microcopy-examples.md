# Microcopy examples

Worked swaps and before/after rewrites for interface text.

## Button labels

| Instead of | Use |
|------------|-----|
| Submit | Send Message |
| OK | Got it |
| Continue | Next: Payment |
| Cancel | Keep Editing |
| Yes / No | Delete / Keep |

- Start with a verb.
- Name the object when a verb alone is ambiguous ("Send Message", not "Send").
- Confirm a destructive action with the specific verb ("Delete project"), not "Yes".

## Error messages

| Instead of | Use |
|------------|-----|
| Error 404 | Page not found. Try searching or go back to the homepage. |
| Invalid input | Enter a valid email address, for example name@example.com. |
| Something went wrong | We couldn't save your changes. Check your connection and try again. |

An error passes when it is specific about the problem, blames no one, gives a fix or next step, and uses plain language rather than a code.

## Empty states

| Screen | Copy |
|--------|------|
| No search results | No results for 'xyz'. Try different keywords or check your spelling. |
| Empty inbox | No messages yet. When someone contacts you, you'll see it here. |
| First run | Your projects will appear here. Create your first project to get started. |

## Success messages

| Instead of | Use |
|------------|-----|
| Success! | Your profile has been updated. |
| Done | Message sent to name@example.com. |
| Saved | Order #12345 confirmed. Shipping in 2-3 days. |

## Voice and tone

Voice is constant; tone shifts with the situation.

| Situation | Tone |
|-----------|------|
| Success | celebratory, warm |
| Error | calm, helpful |
| Warning | serious, clear |
| Onboarding | encouraging, patient |
| Settings | neutral, informative |

## Terminology

- Pick one term per concept and use it everywhere.
- Match the words users already use; check search queries and support tickets.
- Keep sentence case for buttons and labels unless the product style says otherwise.
