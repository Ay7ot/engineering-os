# Ad platform character limits

Verify every element against these before delivering copy. Platforms truncate silently.

## Google Ads, responsive search ads

| Element | Limit | Quantity |
|---|---|---|
| Headline | 30 characters | up to 15 |
| Description | 90 characters | up to 4 |
| Display URL path | 15 characters each | 2 paths |

Structural rules:

- Headlines must read correctly alone and in any random combination.
- Pin a headline to a position only when required; pinning reduces optimisation.
- Include at least one keyword-focused, one benefit-focused and one call to action headline.
- Google allows at most 3 responsive search ads per ad group; group requests larger than that by ad group.

## Meta, Facebook and Instagram

| Element | Limit | Notes |
|---|---|---|
| Primary text | 125 characters visible, up to 2,200 | Front-load the hook |
| Headline | 40 characters recommended | Sits below the image |
| Description | 30 characters recommended | Below the headline |
| Display link | 40 characters | Optional |

## LinkedIn

| Element | Limit | Notes |
|---|---|---|
| Intro text | 150 characters recommended, 600 max | Above the image |
| Headline | 70 characters recommended, 200 max | Below the image |
| Description | 100 characters recommended, 300 max | Appears in some placements |

## TikTok

| Element | Limit | Notes |
|---|---|---|
| Ad text | 80 characters recommended, 100 max | Above the video |
| Display name | 40 characters | Brand name |

## X

| Element | Limit | Notes |
|---|---|---|
| Post text | 280 characters | The ad copy |
| Card headline | 70 characters | Card headline |
| Card description | 200 characters | Card description |

## Static ad templates

Cycle through layout frameworks rather than clustering on favourites; template diversity is angle diversity. Named frameworks include Us versus Them, Stat Callout, Review Card, Before and After, Founder Message, and FAQ Card, each with fixed copy slots and a visual area. Per-concept output should state the template, the headline, the body, the visual description, an image prompt if images are generated, and the grounding source.

## Compliance

For regulated categories, keep the platform and industry rules next to the creative brief, forbid superlatives and outcome promises where the regulator does, use neutral framing, include required disclaimers, and add a geographic qualifier where the offer is region-specific. Check the compliance list before delivery, not after rejection.
