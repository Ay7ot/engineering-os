# knowledge/

Durable, cross-project knowledge — things worth knowing regardless of which
project you're in (architecture patterns, technology notes, engineering
practices, vendor gotchas).

Suggested subfolders (created by `eng setup`):
- `architecture/`
- `engineering/`
- `technologies/`
- `patterns/`

One topic per file. These are indexed by the `engineering-memory` MCP
`search_knowledge` tool.
